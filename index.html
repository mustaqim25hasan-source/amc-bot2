Step 1 — Create a Discord Webhook
1
Open your Discord server on your phone
Go to the channel you want alerts in (e.g. #ticket-alerts)
2
Open Channel Settings
Tap and hold the channel name → Edit Channel
3
Create the Webhook
Go to Integrations → Webhooks → New Webhook
Name it "Ticket Bot" → tap Copy Webhook URL
4
Add to GitHub Secrets
GitHub repo → Settings → Secrets and variables → Actions → New secret
Name: DISCORD_WEBHOOK Value: paste the webhook URL here

GitHub Mobile Setup — Full Walkthrough
1
Go to github.com in your phone browser & log in
Tap + (top right) → New repository
2
Create the repo
Name: amc-bot  ·  Set to Public (needed for free GitHub Pages)  ·  Tap Create repository
3
Upload checker.js
Add file → Create new file → name it checker.js → paste contents → Commit new file
4
Upload watches.json
Add file → Create new file → name it watches.json → go to the Code tab here, tap Copy, paste → Commit new file
5
Create the workflow file
Add file → Create new file → type exactly in the filename box (including slashes):
.github/workflows/check-tickets.yml
Paste the check-tickets.yml contents → Commit new file
6
Upload index.html (this app)
Add file → Upload files → upload the index.html → Commit
This becomes your manager app hosted on GitHub Pages.
7
Enable GitHub Pages
In your repo: Settings → Pages → Source: Deploy from branch → Branch: main → Save

Your app will go live at:
mustaqim25hasan-source.github.io/amc-bot
Bookmark this on your phone AND PC — same site, always in sync!
8
Add all 3 secrets
Settings → Secrets and variables → Actions → New repository secret (add all 3):
PUSHOVER_USER_KEY → your Pushover user key PUSHOVER_API_TOKEN → your Pushover API token DISCORD_WEBHOOK → your Discord webhook URL
9
Enable Actions & run the test
Actions tab → click AMC Ticket Checker → Run workflow → Run workflow
Within 30 seconds you'll get a Pushover notification AND a Discord message confirming everything works!
Bookmark as an app on Android
Open your GitHub Pages URL in Chrome → tap the ⋮ menu → Add to Home Screen
You get an app icon that opens this manager directly. Works on PC in any browser too.
To update your watches later
Open this app on your phone or PC → Watches tab → add/edit/remove → Code tab → Copy → paste into watches.json on GitHub. Done in under 2 minutes.
